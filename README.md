# Smart Binary Search Utility

A Python application that implements the Binary Search algorithm using recursion to efficiently search elements in a sorted array.

## Features
- Recursive Binary Search
- User input support
- Efficient O(log n) search
- Clean and modular Python implementation

## Technologies Used
- Python 3

## Time Complexity
- Best Case: O(1)
- Average Case: O(log n)
- Worst Case: O(log n)
